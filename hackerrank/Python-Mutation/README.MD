# Python Mutations

Solução do desafio **Python Mutations** da plataforma HackerRank.

## 📚 Descrição

Neste desafio, o objetivo é modificar um caractere específico de uma string a partir de sua posição.

O exercício explora um conceito importante da linguagem Python:

- Strings são **imutáveis**.
- Não é possível alterar diretamente um caractere usando índice.
- É necessário criar uma nova string a partir da original.

## 🧠 Conceitos praticados

- Strings
- Imutabilidade
- Listas
- Indexação
- Conversão entre tipos
- Manipulação de caracteres

## 🚀 Exemplo

Entrada:

```text
abracadabra
5 k
```

Saída:

```text
abrackdabra
```

## 💻 Solução

A estratégia utilizada foi:

1. Converter a string para uma lista.
2. Alterar o caractere desejado pela posição recebida.
3. Reconstruir a string utilizando `join()`.

## 🎯 Aprendizados

Durante a resolução deste desafio foram praticados:

- Diferença entre tipos mutáveis e imutáveis.
- Manipulação de índices.
- Uso do método `join()`.
- Conversão de string para lista e vice-versa.
