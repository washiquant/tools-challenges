# What's Your Name?

## 📌 Descrição

Este desafio faz parte da trilha de Python do HackerRank e tem como objetivo praticar a manipulação de strings e a interpolação de variáveis no Python.

O programa recebe o primeiro e o último nome de uma pessoa em linhas separadas. O objetivo é exibir uma mensagem personalizada de saudação utilizando esses nomes.

## 🎯 Objetivo

Implementar a função `print_full_name(first, last)` para:

1. Receber duas strings representando o primeiro nome (`first`) e o sobrenome (`last`).
2. Formatar e imprimir a mensagem no seguinte formato:
   `Hello firstname lastname! You just delved into python.`
   *(onde `firstname` e `lastname` são substituídos pelos valores recebidos).*

## 📥 Entrada

- **Linha 1:** Uma string representando o primeiro nome (`first`).
- **Linha 2:** Uma string representando o sobrenome (`last`).
