# String Split and Join

## 📌 Descrição

Este desafio faz parte da trilha de Python do HackerRank e tem como objetivo praticar a manipulação de strings utilizando operações de separação e junção.

O programa recebe uma string contendo palavras separadas por espaços. O objetivo é transformar essa string substituindo os espaços entre as palavras por hífens (`-`).

## 🎯 Objetivo

Implementar a função `split_and_join(line)` para:

1. Receber uma string contendo palavras separadas por espaços.
2. Separar a string em suas palavras.
3. Juntar novamente essas palavras utilizando um hífen (`-`) como separador.
4. Retornar a nova string.

## 📥 Entrada

Uma única linha contendo palavras separadas por espaços.
